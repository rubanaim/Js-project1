# Healthy Food Store 🥗

A responsive multi-page e-commerce website for a healthy food store, built with HTML, CSS, and JavaScript. Visitors can browse products, add them to a shopping cart, and see the total price update.

🔗 **Live demo:** [https://rubanaim.github.io/Js-project1/](https://rubanaim.github.io/Js-project1/)

## Features
- Landing page with a hero section, about, services, blog, newsletter, and contact sections
- "Top Products" carousel built with Slick Slider (3 slides on desktop, 2 on tablet, 1 on mobile)
- Products page where items are generated dynamically from a JavaScript array
- Shopping cart panel with item counter, product list, and total price
- Back-to-top button
- Embedded Google Map in the contact section
- Responsive layout for different screen sizes

## Built With
- HTML5
- CSS3
- JavaScript (ES6)
- jQuery
- Slick Slider
- Font Awesome icons
